合法练习环境：在自己的电脑上搭靶场

想练手，就在「自己家」练：DVWA、WebGoat、pikachu 等故意留漏洞的靶场，只在本机或隔离网络里运行。

一句话结论靶场是「故意有漏洞的练习用网站」。安全练习的三条铁律：只装在自己的机器/虚拟机里、只监听 127.0.0.1、绝不暴露到公网。因为它们的漏洞是真的，放到公网等于给别人开门。

三个靶场怎么选

DVWA

页面简单，有「安全等级」滑块（低/中/高/不可能），同一个漏洞能看到「写得烂」到「写得对」的代码对比，对学防御特别友好。

WebGoat

OWASP 出品，带分步教程课程，每课先讲原理再让你练。Java 技术栈。

pikachu

中文界面，按漏洞类型分章节，适合入门对照学习。按其 README 搭建 PHP + MySQL 环境。

学习方法（比「通关」更重要）

  1. 先读这个漏洞的原理（本站第 2 课），再去靶场看现象。
  2. 看到现象后，去看源码为什么会这样；再看「安全等级高」时源码是怎么修的。
  3. 自己动手把有洞的代码改对，再验证。
  4. 每个漏洞写一页笔记：成因 → 现象 → 修复 → 一个现实中的例子。

常见误区

「在云服务器上搭个靶场，方便远程练」一旦被扫描器发现，你的服务器可能被真正入侵。要放就加访问控制，仅允许你自己的 IP。
「靶场通关很快就能去挖真站了」靶场很「干净」，真实世界复杂得多，而且还要有授权。先读公开报告、学规则。
「在靶场里用的账号密码可以复用我的」永远用一次性的假密码。
