SRC 学习路线图

基本功 → 靶场 → 读公开报告 → 合规参与。每一步都有可勾选的小目标，进度保存在你的浏览器里。

一句话结论挖洞不是「会几个工具」，而是懂原理 + 有耐心 + 守规矩。路线很朴素：先把 Web 是怎么工作的搞懂，再在靶场练，再大量读别人的报告，最后在授权范围内小步参与。
总进度

心态与习惯

  • 先守规则，再追技术：一次越界，可能毁掉整个职业路径。
  • 写笔记、写复盘：每个知识点都能讲给别人听，才算会。
  • 从防御视角学：知道怎么修，才真懂为什么会出洞。
  • 接受低回报的前期：热门项目竞争激烈，重复、无效很常见，这是正常的。

常见误区

「先学一堆工具就能上手」工具只是放大器，不懂 HTTP、会话、数据库，就看不懂工具输出。
「只追求高危、赏金」先追求把一个漏洞类型彻底学透。
「别人的报告不需要看」公开报告是最好的免费教材，能学到思路和写法。
