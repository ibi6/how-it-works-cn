SSRF 服务端请求伪造

让服务器替你去访问"你自己访问不了"的地方

定义类比成因危害防御审计视角本地实验靶场小测验误区报告模板
一句话定义SSRF 是指：服务端会根据用户提供的 URL 去发起请求，攻击者借此让服务器去访问内网、本机或云元数据等"外部无法直接访问"的资源。
本课只讲原理、防御与审计思路。所有演示都是浏览器里的假数据模拟；不提供针对真实目标的攻击载荷清单，也请只在自己搭建的环境或获得授权的范围内验证。

🏠 生活类比

公司前台有一条规矩："访客说想要哪份文件，我就进内部档案室去拿"。如果访客说"请把保险柜里的文件拿来"，前台照办了。前台有内部通行证，而访客没有。

🔍 成因：问题到底出在哪

常见于"远程拉取"类功能：URL 预览/抓取、图片转存、Webhook、导入、PDF 生成、第三方登录回调。服务器所处的网络位置有特权。

直接使用 URL

没做任何限制。

// 有漏洞
url = request.args["url"]
img = http_get(url)        // 想访问谁就访问谁
return img

弱校验

只检查字符串，如"URL 以 example.com 开头"或黑名单 127.0.0.1。

if "127.0.0.1" not in url:      // 字符串黑名单
    http_get(url)
// 域名解析、进制写法、跳转都可能绕过字符串检查

跟随跳转

校验了第一个 URL，但允许 302 跳到别处。

http_get(url, follow_redirects=True)   // 跳转目的地未校验

💥 危害与等级

严重访问云厂商元数据服务取得临时凭证，进而控制云资源；访问内网管理后台。
高探测内网存活服务、读取内网接口数据。
中只能访问外网、且无回显（Blind SSRF），可用于端口/存活探测。
决定等级的因素能否回显响应内容、能访问的内网是什么、是否在云环境、能否使用非 HTTP 协议。

🛡 防御与修复

修复原则：只允许访问明确列出的目标；解析后校验 IP；不跟随未校验的跳转。

// 1) 能用白名单就用白名单（只允许已知域名）
ALLOW = {"img.example.com", "cdn.example.com"}

// 2) 必须开放时：自己解析 DNS，对"解析后的 IP"做校验，再用该 IP 连接（防 DNS 重绑定）
ip = resolve(host)
if ip.is_private or ip.is_loopback or ip.is_link_local: abort(400)

// 3) 仅允许 http/https，禁止 file/gopher 等
// 4) 禁用自动跳转，或每一跳都重复校验
// 5) 出站网络隔离：抓取服务放在无内网访问权限的子网；云上启用更安全的元数据访问方式（如 IMDSv2）
// 6) 不把响应原样回显给用户

🧐 怎么判断自己安全？代码审计视角

  • 找所有"服务器去请求用户给的地址"的功能：预览、导入、回调、截图、文件转存。
  • 校验是在字符串层面，还是解析后的 IP 层面？跳转、IPv6、DNS 重绑定是否考虑？
  • 抓取服务所在网络是否可访问内网与元数据地址？
  • 错误信息是否区分"连得上/连不上"（会变成探测器）？

✅ 小测验

⚠ 常见误区

「只允许 https 就安全」内网的 https 服务依然存在。
「过滤了 localhost / 127.0.0.1 就够了」IP 有多种写法，域名可解析到内网，应在解析后校验。
「内网服务没有认证因为在内网」SSRF 正是把"可信内网"变成攻击面。

📝 SRC 报告里怎么描述（虚构示例模板）

下面是完全虚构的示例（example.test 不是真实站点）。注意三点：标题含等级与位置、复现步骤最小化且只用自己的账号、说明影响但不扩大验证。写法细则见 漏洞报告与沟通。

标题：【高危】example.test 链接预览功能 SSRF 可访问内网服务（虚构示例） 目标/接口：POST https://app.example.test/api/preview {"url": ...}（虚构） 漏洞概述：预览接口会由服务端请求用户提供的 URL 并回显内容，未限制目标地址。 复现步骤： 1. 提交指向自己控制的服务器的 URL，在自己服务器日志看到来自目标的出站请求，证明服务端会发起请求。 2. 用规则允许范围内的最小验证：请求一个明确属于测试环境的内部健康检查地址，响应被回显。 3. 未访问元数据、未读取任何凭证或业务数据。 影响：可访问内网服务；云环境下可能进一步取得凭证（未验证）。 修复建议：目标白名单；解析后 IP 校验；禁用跳转；出站隔离；不回显响应。 自评等级：高危（可内网访问且有回显）。
