安全配置错误

产品本身没问题，是"没拧紧"的螺丝

定义类比成因危害防御审计视角本地实验靶场小测验误区报告模板
一句话定义安全配置错误是指：系统、框架、云服务、Web 服务器在部署时使用了不安全的默认值、遗漏了加固步骤，或开启了不必要的功能。
本课只讲原理、防御与审计思路。所有演示都是浏览器里的假数据模拟；不提供针对真实目标的攻击载荷清单，也请只在自己搭建的环境或获得授权的范围内验证。

🏠 生活类比

新买的保险箱，出厂密码是 0000，说明书说"请自行修改"，你没改；窗户装了锁，但一直开着。

🔍 成因：问题到底出在哪

常见于运维与部署环节，也是 OWASP Top 10 的常客。特点：不需要写复杂利用，只要"配置没改"。

默认与调试

默认账号密码、示例应用、调试接口（如监控面板）、管理控制台暴露在公网。

admin / admin       示例页面 /examples/       /actuator/*（未鉴权）

过宽的权限与跨域

对象存储桶公开读写；CORS 允许任意来源并带凭证；数据库端口对公网开放；服务账号权限过大。

Access-Control-Allow-Origin: 反射 Origin
Access-Control-Allow-Credentials: true

缺少加固与未更新

缺少安全响应头；TLS 配置弱；目录列表开启；组件有已知漏洞未升级。

Options +Indexes   // 目录列表
缺少：Content-Security-Policy / X-Content-Type-Options / HSTS

💥 危害与等级

严重管理控制台未鉴权、存储桶公开导致大规模数据泄露。
高默认口令的后台、数据库公网暴露。
中缺少安全头、目录列表、低风险信息暴露。
决定等级的因素暴露的资产价值、是否可直接利用、是否需要认证。

🛡 防御与修复

修复原则：安全基线 + 自动化检查 + 最小开放。

// 1) 建立基线：镜像/服务器模板加固后再发布（关调试、改默认口令、删示例）
// 2) 最小开放：安全组/防火墙默认拒绝，管理端口仅内网/VPN
// 3) 存储桶与云资源：默认私有，权限最小化，定期审计
// 4) 响应头：
Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Content-Type-Options: nosniff
Content-Security-Policy: default-src 'self'
// 5) CORS：精确白名单，勿反射 Origin；带凭证时尤其严格
// 6) 依赖与组件：软件物料清单 + 漏洞订阅 + 定期升级
// 7) 配置即代码 + CI 扫描（IaC 检查），变更评审

🧐 怎么判断自己安全？代码审计视角

  • 部署清单：默认账号是否修改？示例/调试端点是否移除？
  • 云控制台：存储桶、数据库、安全组是否有公开项？
  • HTTP：响应头、CORS、Cookie 属性、TLS 版本。
  • 组件版本：与已知漏洞库（如 CVE）对照；是否有升级计划？

✅ 小测验

⚠ 常见误区

「内网所以不用管」内网一旦有入口，配置缺陷就是放大器。
「默认配置是官方推荐的所以安全」默认值常为易用而非安全。
「扫一遍就一劳永逸」配置会漂移，需要持续检查。

📝 SRC 报告里怎么描述（虚构示例模板）

下面是完全虚构的示例（example.test 不是真实站点）。注意三点：标题含等级与位置、复现步骤最小化且只用自己的账号、说明影响但不扩大验证。写法细则见 漏洞报告与沟通。

标题：【高危】example.test 对象存储桶公开可列目录（虚构示例） 目标/接口：https://static-bucket.example.test/（虚构） 漏洞概述：存储桶允许匿名列出对象，包含用户上传的发票文件名。 复现步骤： 1. 以匿名方式访问桶根地址，返回对象列表。 2. 仅查看列表的前几项文件名，用于证明；未下载任何文件。 影响：若对象可读，将泄露用户发票与个人信息。 修复建议：关闭公共访问；通过签名 URL 提供下载；开启访问日志。 自评等级：高危。
