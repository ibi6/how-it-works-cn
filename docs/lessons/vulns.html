常见 Web 漏洞详解

每个漏洞一课，结构相同：定义 → 类比 → 成因（含有漏洞的代码）→ 危害分级 → 防御（正确代码）→ 审计视角 → 本地实验 → 靶场 → 小测验 → 误区 → SRC 报告模板。

只讲原理与防御；演示全部是浏览器内的假数据模拟；请只在自己搭建的环境或授权范围内验证。先读 第 1 课：合法边界。

建议学习顺序

先「注入类」理解"数据变指令"，再「访问控制类」理解"少一道检查"，最后「配置与逻辑类」。

学完怎么办

  • 对照 本地靶场，把每课"靶场练习"做一遍，并尝试读源码找出缺失的那一道检查。
  • 用每课的"报告模板"，为靶场里的漏洞写一份练习报告。
  • 再去读 学习路线图。
